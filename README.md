## Что сделано

1. **Java 17 и три копии ZooKeeper 3.9.6** в `zk/server1..3`. У каждой копии свой `conf/zoo.cfg`: строки `server.1..3` одинаковые, а `clientPort` (2181, 2182, 2183) и `dataDir` с файлом `myid` свои.
2. **Ансамбль.** Роли смотрю командой `srvr`, потому что `zkServer.sh status` на macOS с 3.9.6 всегда отвечает «Error contacting service» (подробности в отчёте). Лидер остановлен, и ансамбль работает с новым лидером. После остановки второго сервера оставшийся не обслуживает запросы, клиент получает `ConnectionLoss`. Серверы запущены обратно, данные на месте.
3. **Эфемерный узел** из второго окна `zkCli` пропадает через 30 с после закрытия окна (тайм-аут сессии) и сразу после `quit`.
4. **Координатор** `lab/coordinator.py` поверх MapReduce из ДЗ-3 (`lab/mapreduce.py` и `lab/common.py` без изменений):
   - выборы лидера рецептом `Election` из kazoo, тайм-аут сессии 10 с;
   - эпоха в `/hh/epoch`, новый лидер увеличивает её запросом `multi` вместе с проверкой своего узла выборов;
   - манифест задания `/hh/job` (объект, ETag, размер чанка), все Range GET идут с `If-Match`;
   - чекпоинт после каждой map-задачи: результат задачи в S3, отметка в `/hh/checkpoint/task-NNNN`;
   - публикация: файлы в свою папку в S3, затем указатель `/hh/result`. С `FENCING=1` указатель пишется запросом `multi` с проверкой версии `/hh/epoch`.
5. **Пауза лидера без защиты** (`docker pause` примерно на 40 с). Запасной координатор стал лидером через 10–12 с, взял 8 задач из чекпоинта и досчитал 18. Результат совпал с ДЗ-3 побайтно. Старый лидер после паузы записал результат второй раз, указатель получил версию 2.
6. **То же с `FENCING=1`.** Запись старого лидера (эпоха 5) отклонена с `BadVersionError`, в указателе остался результат запасного координатора (версия 1, эпоха 6). Счётчик эпох между прогонами не сбрасывается, `reset` его только увеличивает.

## Как запустить

Нужны Docker Desktop и хранилище из ДЗ-3: контейнер `rustfs` в сети `hhnet` с бакетом `hh-lake` (`scripts/01_storage.sh` в hh-mapreduce).

```bash
bash scripts/00_setup.sh       # java 17, три копии zookeeper 3.9.6, образ с kazoo
bash scripts/01_ensemble.sh    # ансамбль, роли, остановка одного и двух серверов
bash scripts/02_ephemeral.sh   # эфемерный узел
bash scripts/03_failover.sh    # пауза лидера без защиты
bash scripts/04_fencing.sh     # то же с FENCING=1
bash scripts/05_report.sh      # pdf-отчёт
bash scripts/99_stop.sh        # остановить серверы
```
